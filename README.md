# Simulation

Simulation projects, organized by paradigm.

## Structure
- `discrete event simulation/` — discrete-event models (Simio)
- `system dynamics simulation/` — system dynamics models (Vensim)

## Adding a project
Create a new folder under the matching paradigm, e.g.
`discrete event simulation/<project-name>/`, with its own README describing
the model, the software/version used, and how to run it.
